# Vendor Renewal Tracker

A public-safe, local-only Day 5 build from the UBuildOS 30-day public campaign.

## The real-world problem
A small-business owner or operations manager can have software subscriptions, insurance, service contracts, licenses, and vendor agreements renewing on different dates. Missing one notice window can turn a routine renewal into an avoidable surprise.

## What this build does
Vendor Renewal Tracker shows synthetic renewals as OVERDUE, DUE_7, DUE_30, DUE_60, LATER, or REVIEW using explicit calendar-day rules. Every row shows an owner and can be exported to CSV.

## What it does not do
It does not cancel, buy, pay, negotiate, contact vendors, access vendor accounts, recommend renew/cancel decisions, or use real customer/vendor data.

## Run locally
Open `index.html` in a modern browser. No build step or required runtime network service is needed.
